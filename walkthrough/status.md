# The status bar item

It sits at the right end of the status bar and shows, from left to right:

- Claude Code tokens and estimated cost since local midnight
- Codex tokens and estimated cost since local midnight
- the clock icon with the time left in the current Claude Code 5-hour block
- the Codex 5-hour and weekly limits, in percent used

Hover it for the input, output and cache split and the reset times. It turns yellow when a Codex limit reaches 90%. Click it to open the dashboard.
